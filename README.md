## 🎯 项目核心洞察
- **高贡献度**：通过 RFM 模型识别出占总人数 20% 的“重要价值客户”，贡献了超过 60% 的总营收。
- **数据清洗**：独立处理了 4000+ 条脏数据，包括退货订单处理及 CustomerID 缺失值清洗。

## 🛠️ 技术栈
- **Pandas**: 指标计算与分箱逻辑
- **PyEcharts**: 动态环形图渲染
